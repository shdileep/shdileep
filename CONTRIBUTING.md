# Profile Maintenance Guidelines

This repository powers the personal GitHub profile README for [Dileep Sai Galla](https://github.com/shdileep).

## Directory Structure

- `assets/` - SVG section headers, custom banner cards, and tech stack components.
- `assets/icons/` - High-resolution application and social icons.
- `README.md` - Main profile layout with responsive grid and interactive badges.

## Asset Standards

- Vector assets (`.svg`) should be optimized with standard viewport dimensions.
- Application icons should have consistent dimensions (48x48 px or 36x36 px for socials).
- External links must target live deployments or public repositories.
